TIDEBOUND INSTALLER PARTS
=========================
1. Open Roblox Studio, sign in, create a Baseplate place.
2. Open View > Command Bar (or View > Output and click the command bar box).
3. Type:  print('ok')  and press Enter. You should see 'ok' in the Output window.
4. Open part_01...luau in Notepad. Select ALL (Ctrl+A), Copy (Ctrl+C).
5. Click inside the Command Bar, paste (Ctrl+V), press Enter.
6. Wait for: [Installer] Part 1/N complete.
7. Repeat for every part in order.
8. Done! You should see [Tidebound] Server booted after pressing Play.
